# Калькулятор суточной нормы КБЖУ

## 📋 Описание проекта

Веб-приложение для расчета и отслеживания суточной нормы калорий, белков, жиров и углеводов (КБЖУ). Приложение предназначено для людей, занимающихся фитнесом и следящих за питанием, особенно для тех, кто хочет набрать мышечную массу.

## ✨ Основные возможности

- **Расчет индивидуальной нормы КБЖУ** на основе веса пользователя
- **Учет потребляемых продуктов** с детальной информацией о пищевой ценности
- **Визуализация прогресса** в виде процентного соотношения и прогресс-баров
- **Хранение сессии** добавленных продуктов
- **Адаптивный интерфейс** с интуитивно понятным управлением

## 🔌 API endpoints

### `GET /`
**Описание:** Главная страница с интерфейсом калькулятора

### `POST /api/calculate`
**Описание:** Расчет процента от нормы КБЖУ

**Параметры:**
```json
{
  "weight": 70.0,
  "current": {
    "calories": 295.0,
    "protein": 33.7,
    "fats": 3.9,
    "carbs": 28.0
  }
}
```

### `POST /api/add_product`
**Описание:** Добавление продукта в текущую сессию

**Параметры:**
```json
{
  "name": "Яблоко",
  "calories": 52.0,
  "protein": 0.3,
  "fats": 0.2,
  "carbs": 14.0,
  "session_id": "default"
}
```

### `POST /api/clear_session`
**Описание:** Очистка текущей сессии

## 📊 Формулы расчета

### Нормы для набора массы
- **Калории**: вес (кг) × 38 ккал
- **Белки**: вес (кг) × 2.0 г
- **Жиры**: вес (кг) × 1.2 г
- **Углеводы**: (калории - (белки×4 + жиры×9)) ÷ 4

### Расчет процентов
```
процент = (потреблено / норма) × 100%
```
