# Калькулятор КБЖУ (PLM)

Веб-приложение для расчета суточной нормы калорий, белков, жиров и углеводов (КБЖУ) для набора мышечной массы.

## 📋 Описание

Этот калькулятор помогает отслеживать потребление макронутриентов и сравнивать их с рекомендуемыми нормами для набора массы. Приложение позволяет:

- Рассчитать индивидуальную норму КБЖУ на основе веса
- Добавлять продукты и отслеживать их калорийность
- Визуализировать прогресс достижения суточной нормы
- Управлять списком потребленных продуктов

## ✨ Основные возможности

- **Расчет нормы КБЖУ**: Автоматический расчет на основе веса пользователя
  - Калории: 38 ккал на кг массы тела
  - Белки: 2 г на кг
  - Жиры: 1.2 г на кг
  - Углеводы: рассчитываются автоматически из оставшихся калорий

- **Учет продуктов**: Добавление продуктов с указанием их пищевой ценности
- **Визуализация прогресса**: Наглядные индикаторы процента достижения нормы
- **Управление сессией**: Возможность очистить список продуктов и начать заново

## 🚀 Установка и запуск

### Требования

- Python 3.7+
- pip (менеджер пакетов Python)

### Установка зависимостей

```bash
pip install fastapi uvicorn pydantic jinja2 python-multipart
```

### Запуск приложения

```bash
python main.py
```

Приложение будет доступно по адресу: [http://localhost:8000](http://localhost:8000)

## 🎯 Использование

1. **Введите свой вес** в килограммах
2. **Добавьте продукты**, которые вы употребили:
   - Введите название продукта
   - Укажите калории, белки, жиры и углеводы
   - Нажмите "Добавить продукт"
3. **Нажмите "Рассчитать"** для просмотра результатов:
   - Ваша норма КБЖУ
   - Текущее потребление
   - Процент достижения нормы
4. **Используйте "Очистить"** для начала новой сессии

## 🔧 API Endpoints

### GET `/`
Главная страница приложения

### POST `/api/calculate`
Расчет КБЖУ и процента от нормы

**Параметры запроса:**
```json
{
  "weight": 70.0,
  "current": {
    "calories": 500.0,
    "protein": 50.0,
    "fats": 20.0,
    "carbs": 60.0
  }
}
```

**Ответ:**
```json
{
  "norms": {
    "calories": 2660.0,
    "protein": 140.0,
    "fats": 84.0,
    "carbs": 336.0
  },
  "percentages": {
    "calories": 18.8,
    "protein": 35.7,
    "fats": 23.8,
    "carbs": 17.9
  },
  "average": 24.0,
  "current": {...}
}
```

### POST `/api/add_product`
Добавление продукта в сессию

**Параметры запроса:**
```json
{
  "session_id": "default",
  "name": "Куриная грудка",
  "calories": 165.0,
  "protein": 31.0,
  "fats": 3.6,
  "carbs": 0.0
}
```

**Ответ:**
```json
{
  "total": {
    "calories": 165.0,
    "protein": 31.0,
    "fats": 3.6,
    "carbs": 0.0
  },
  "products": [...]
}
```

### POST `/api/clear_session`
Очистка текущей сессии

**Параметры запроса:**
```json
{
  "session_id": "default"
}
```

## 📝 Формулы расчета

Приложение использует следующие формулы для расчета нормы КБЖУ для набора массы:

- **Калории**: Вес (кг) × 38 ккал
- **Белки**: Вес (кг) × 2.0 г
- **Жиры**: Вес (кг) × 1.2 г
- **Углеводы**: (Калории - (Белки × 4 + Жиры × 9)) / 4

## ⚠️ Примечания

- Данные хранятся в памяти сервера и сбрасываются при перезапуске
- Формулы расчета являются упрощенными и предназначены для общих рекомендаций
- Для точного расчета индивидуальной нормы рекомендуется консультация со специалистом
